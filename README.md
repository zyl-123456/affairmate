# AffairMate · 事务伴侣

> An AI-powered personal affairs & time management app. Chat to maintain two knowledge bases (matters + four-dimension energy state), and let the AI schedule your day with reasons.

**内置 AI 的个人事务与时间管理软件**——通过日常对话，AI 自动维护两个属于你的知识库：事项库（内核三属性 + 开放扩展层）和状态认知库（身体/认知/情绪/动机四维电量）。安排模式下说一句「安排我接下来两小时」，AI 基于全部认知给出带理由的日程。

## ✨ Features

### 💬 对话与知识库
- **双模式对话**：沟通模式（聊事务与状态，AI 自动打标入库）/ 安排模式（一句话出带理由日程）
- **双知识库**：事项库（时间/精力/独占性内核 + 无限扩展属性）；状态库（四维电量 + 时段轨迹历史）
- **目标账本**：目标-要求-进度三层（要求驱动，不猜完成）；事项挂靠；执行史追加；全端人工管理（长按）
- **个人说明书**：AI 从对话与复盘中沉淀你的画像/规律/充电法/偏好，越用越懂你
- **用户画像**：称呼、身份时间线，由对话自动维护

### 📅 智能日程
- **晨报机制**：睡前说「睡8小时，晨报」→ 醒来铃声循环响 + AI 规划全天（显式制：说了"晨报"才出）
- **对话设闹钟**：自然语言（「半小时后叫我」「设个5分钟的闹钟」）本地正则秒设 + AI 兜底自学习闭环
- **日程全能调整**：太紧了→智能重排；两件事同时做→双轨并行；删/挪/改→清空重建一步到位
- **24h 双条时间轴**：上/下午各撑满屏宽；24 色跳色配色；块内短名；点击色块看详情
- **闹铃卡片**：历史闹钟 ✅响过 / ⏰待响 / ⚠️未响 三态可追溯，跟日历回看

### ⚡ 工程可靠性
- **多供应商 LLM**：OpenAI 兼容协议；智谱 GLM（含 Coding Plan）/ DeepSeek / Kimi 预设；自定义端点
- **流式输出**：逐字显示 + 25s 看门狗 + 耗时分解（建连/首字/全程）诊断
- **思考分级**：日常指令关思考秒回；晨报/复盘开思考保质量
- **作业单回执**：AI 操作被拒自动补救一轮（轻量 ReAct——AI 看得见执行结果）
- **Token 计量**：每轮输入/输出用量随气泡展示；报文大小进日志
- **使用日志**：全程记录（发送/耗时/token/操作/错误含 Doze 嫌疑标注），日期筛选，问题定位利器
- **语音输入**：按住说话（Android）
- **数据本地优先**：原子写入 + 备份自愈；API Key 仅本地；遥测默认关闭；电池优化豁免引导保后台联网

## 🚀 Getting Started

```bash
cd app
flutter pub get
flutter run                    # 或 flutter run -d windows
```

- Flutter 3.24.x / Dart 3.5.x
- Android minSdk 26（Android 8.0+）/ Windows 桌面预览
- 首次使用：启动后进入右上角「设置」→ 从预设添加供应商 → 填入 API Key

## 🗂 Project Layout

```
app/
  lib/
    data/       # 模型与仓储（matters/goals/state/playbook/schedule/alarm_log/usage_log）
    llm/        # LLM 客户端（流式/思考分级/多供应商）、提示词、通知、铃声、闹钟播放
    pages/      # 沟通/展示/目标/懂我/设置
    platform/   # 电池豁免等原生桥
    state.dart  # 全局状态中枢
  test/         # 61 项测试（单元 + e2e 全链路）
  integration_test/
tools/          # 构建流水线 / 发布同步 / 并行开发
docs/           # 使用说明
```

# 事务伴侣 · Windows 预览版使用说明

版本：M-016（2026-09-04）｜对应验收标准 A-002 / A-003

> 本文件是使用说明的**版本库正本**（docs/使用说明-Windows预览版.md）；
> `预览版-Windows/` 下的副本由构建时同步，勿直接改副本。

## 一、首次启动（约 1 分钟）

1. 双击 `shiwu_companion.exe`；
2. 点**右上角齿轮**进入设置；
3. 从预设列表点一家供应商：
   - **开了智谱 Coding Plan 订阅** → 选「智谱 GLM Coding Plan（订阅专属通道）」；**注意**：Key 必须用套餐页（个人编程套餐→套餐概览→新建 API Key）生成的，普通 Key 配这条通道会报"1113 余额不足"
   - 按量付费 → **智谱 GLM-5.3**（旗舰，当前限免）或 **GLM-4.7-flash**（永久免费）
4. 填 API Key → 保存（默认设为使用中）；
5. 点该供应商右侧菜单 → **测试连接**，看到「✅ 连接成功」即可开聊。

> 你的 Key 只存在本机（软件私有目录），不进任何版本库/云端。
> 首次联网如弹出 Windows 防火墙许可，请点「允许」——否则模型请求会被拦截。

## 二、验收场景实测（对着需求文档 A-002/A-003）

**场景一 · 沟通模式自动建档（A-002）**
1. 底部导航第 1 页「沟通」，输入：`下周三要交报表`
2. 预期：AI 回一句人话，气泡下有绿色摘要「· 新增『交报表』」；带截止属性
3. 再输入：`报表交了`
4. 预期：摘要显示「· 归档『交报表』」，事项转入归档列表（展示页可见，归档只存名称）

**场景二 · 安排模式自动落进度条（A-003）**
1. 底部导航第 2 页「安排」，输入：`安排我接下来两小时`
2. 预期：AI 给出文字安排+理由；
3. 切到第 3 页「展示」：24h 时间条上自动出现彩色安排块（悬停/长按看理由）；
4. **关掉 App 重开** → 今日安排仍在（重启不丢）；
5. 再说 `安排我今晚八点到十点` → **上午的安排还在**，晚上新增一块（多轮安排合并不互相覆盖）。

**连续对话（上下文）**
- 先说 `下周三要交报表`，再补 `改到周四了` → 预期能正确更新截止日（模型理解指代）。

**状态积累（REQ-004 渐进填充）**
- 随口说：`昨晚没睡好，有点累` → 展示页「今日状态」身体维出现描述；
- 四维（身体/认知/情绪/动机）聊到哪补到哪，不必一次说全。

## 三、界面速览

| 页 | 干什么 |
|---|---|
| 沟通 | 日常聊事务与状态，AI 自动维护两库；语音输入为**安卓端专属**（Windows 预览版按住麦克风会提示"暂不支持"，属正常——speech_to_text 无 Windows 实现） |

## 四、常见问题

- **「⚠️ 还没配置模型供应商」**：去设置页配 Key 并设为使用中。
- **发送按钮点不动/一直转圈**：首次联网弹的防火墙没点「允许」，或供应商不可达——现在请求 90 秒必超时并报错恢复，不会再永久卡死；配置好供应商后重试。
- **「⚠️ 模型调用失败 HTTP 401」**：Key 错了；「HTTP 404」：Base URL 或模型名不对（设置里编辑；预设已对齐 2026-09 现役模型名）。
- **安排块没出现**：换家供应商或把请求说得更具体——模型偶发不守协议时 App 容错降级为纯文字，不崩溃。
- **操作被拒（摘要里"丢弃/歧义"）**：模型给的定位信息对不上库（如同名事项多条），换个说法指明具体事项即可。
- **深色模式**：自动跟随系统。
- 数据文件位置：`C:\Users\<你>\AppData\Roaming\cn.affairmate.shiwu_companion\`（matters/state/schedule/chat 四库 + config；全部原子写入+自动备份，断电不丢）。

## 五、数据安全（M-015）

所有数据文件三重防护：**原子写入**（绝不半截）→ **自动备份**（.bak）→ **自愈**（主文件损坏自动从备份恢复）。正常使用无需关心。
